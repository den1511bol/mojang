# Маджонг ∞

Красивый маджонг-солитёр для Android с бесконечными уровнями.
Снимайте пары одинаковых свободных плиток: плитка свободна, если сверху ничего нет
и слева или справа пусто.

**Разработчик:** @yfeeeee

## Что внутри

- Бесконечные уровни: каждый генерируется процедурно и всегда решаем.
  Чем выше уровень, тем больше плиток, слоёв и разных символов.
- Анимации: плитки падают с отскоком и пылью, выбранная приподнимается и светится,
  пара замахивается и сталкивается со вспышкой, кольцами и искрами, потом рассыпается
  на осколки с физикой; при ошибке плитки дрожат красным; перемешивание переворачивает
  плитки волной; победа - конфетти и салют. Живой ночной фон со звёздами и огоньками.
- Звуки синтезируются в коде (клак плиток, колокольчики, дребезг, фанфары),
  плюс вибрация. Звук можно выключить кнопкой вверху.
- Комбо за быстрые пары, очки, рекорд, звёзды за уровень, подсказка, перемешивание.
- Прогресс сохраняется. Все материалы нарисованы с нуля.

## Как получить APK

Каждый push в `main` запускает GitHub Actions (**Build APK**).
Откройте вкладку **Actions** → последний запуск → артефакт `mahjong-infinity-apk` → `app-debug.apk`.
Вручную: Actions → Build APK → Run workflow.

Локально: откройте папку в Android Studio и нажмите Run.

Kotlin + Jetpack Compose.
